# Первая версия для показа

## Как запустить

Из PowerShell в папке проекта:

```powershell
.\run_first_version.ps1
```

Скрипт запускает тесты, проверяет настройки, строит графы, SVG и учебные материалы, а затем проверяет всю папку результата. Адрес последнего запуска сохраняется в `data/LATEST_RUN.json`.

Для показа через браузер:

```powershell
.\run_web.ps1
```

На странице можно отдельно:

1. выбрать одну из 15 профессий и создать конфигурацию;
2. запустить полный демо-сценарий без HH;
3. запустить настоящий HH-сбор после появления токена;
4. проверить последний результат.

## Что показать Никите

- `review_report.html` — вакансии, грейды, навыки и исходные фрагменты;
- `output/profession_graphs/` — три графа;
- папку `profession_graph_node_images_<date>` — SVG, словарь и лицензии;
- папку `profession_graph_node_courses_<date>` — учебные ссылки и покрытие;
- `scoring_components.json` — прозрачный расчёт count;
- `grade_conflicts.json` — спорные грейды;
- `validation_report.json` — итог автоматической проверки.

## Честные ограничения

- настоящий сбор HH ждёт токен;
- демо проверяет механику, а не репрезентативность рынка;
- словарь, зарплатные пороги и спорные решения ещё нужно утвердить;
- AI-интеграция готова технически, но выключена без выбранного провайдера и ключа;
- SVG сейчас собственные шаблонные, а не фирменные логотипы.
