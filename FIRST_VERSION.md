# Первая версия для показа

## Как запустить

Из PowerShell в папке проекта:

```powershell
.\run_first_version.ps1
```

Команда сама:

1. находит Python 3.12 или новее;
2. запускает автоматические тесты;
3. проверяет конфигурацию и словари;
4. строит графы по демонстрационным вакансиям;
5. проверяет целостность всей папки результата;
6. сохраняет адрес последнего запуска в `data/LATEST_RUN.json`.

Для быстрого повторного запуска без тестов:

```powershell
.\run_demo.ps1
```

## Что показывать

- `review_report.html` — понятный отчёт по вакансиям, грейдам и найденным навыкам;
- `output/profession_graphs/` — три итоговых графа;
- `grade_conflicts.json` — спорные решения по грейдам;
- `phrase_candidates.json` — новые профессиональные фразы для проверки;
- `boilerplate_report.json` — исключённые рекламные блоки;
- `output/validation_report.json` — результат продуктовых проверок.

## Что уже считается рабочим

- файловый и HH-сборщики;
- история исходных карточек;
- очистка и разбор разделов вакансии;
- словарное извлечение с доказательствами;
- осторожное выделение новых профессиональных фраз;
- рабочий словарь из 63 нод ML-инженера;
- Junior, Middle и Senior с уточнениями Intern и Lead;
- отдельная обработка конфликтов грейда;
- расчёт `count`, строгие графы, SVG и отчёты;
- ручная проверка результата через HTML и JSON.

## Что пока временное

- пороги грейдов и политика конфликтов должны быть подтверждены Никитой;
- коэффициенты `count` пока рабочие, но не утверждённые;
- девять спорных нод лежат в `dictionaries/candidate_nodes.json`;
- решения из `review_decisions_template.json` не применяются автоматически;
- учебные материалы пока представлены пустыми списками;
- SVG остаются безопасными шаблонами;
- нет серверного API, базы данных и планировщика;
- контактный `HH-User-Agent` проверен, но анонимный запрос получил `403`; для продолжения нужен токен приложения.
