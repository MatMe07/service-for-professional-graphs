# Changelog

## 0.9.0

- Добавлен полностью автоматический сбор вакансий без ключа через официальный открытый API «Работа России».
- По выбранной профессии автоматически используются запросы каталога, период изменений, пагинация и необязательные коды регионов.
- Добавлены команда `public-search`, кнопка в локальном интерфейсе, сохранение сырых ответов и указание источника.
- Поля «Работы России» приводятся к общей модели вакансии: название, работодатель, регион, требования, обязанности, опыт, зарплата и навыки.
- Малые ветки графа автоматически сворачиваются без потери листьев, чтобы реальные выборки проходили строгое правило минимум трёх дочерних нод.
- Реальный проверочный запуск собрал 34 вакансии Python-разработчика и успешно сформировал три графа.

## 0.8.0

- Добавлен ручной импорт прямых публичных страниц вакансий HH без токена.
- Импорт принимает только ссылки `https://hh.ru/vacancy/<id>`, не ищет вакансии автоматически и не обходит CAPTCHA или ограничения.
- Добавлены кнопка в локальном интерфейсе и команда `hh-public`.
- API-сбор разбивает период на настраиваемые временные окна.
- Нормализация файловых вакансий теперь учитывает отдельные поля обязанностей, требований, условий и ключевых навыков.
- Добавлены журнал ручных операций над нодами, сохранение входных запросов, проверка глубины графа, целевого числа листьев и сходства графов грейдов.
- Добавлен подробный отчёт `TZ_COMPLIANCE.md` по 99 требованиям.

## 0.7.0

- Добавлен настраиваемый каталог из 15 IT-профессий и генерация HH-конфигурации по названию или slug.
- Формула `count` приведена к согласованной доле уникальных вакансий в процентах; прежняя взвешенная формула оставлена только как совместимый режим.
- Грейд может определяться по опыту, зарплате, сигналам в тексте или их комбинации; все пороги вынесены в конфигурацию.
- Канонический словарь расширен до 143 стартовых IT-нод.
- Добавлен каталог официальных учебных материалов, нормализация ссылок, проверка провайдера и отчёт покрытия.
- SVG получили пять собственных шаблонов по типу ноды, словарь происхождения и лицензию проекта.
- Добавлены локальная веб-страница и API с отдельными действиями для профессии, демо, HH и проверки результата.
- Добавлена необязательная AI-интеграция для предложений новых нод без автоматической публикации и передачи сырых вакансий.
- Добавлены `run_web.ps1`, новые команды CLI, схемы и автоматические тесты.

## 0.6.0

- Рабочий словарь ML-инженера расширен с 9 до 63 нод.
- Девять спорных технологий вынесены в отдельный файл кандидатов.
- Грейды получили баллы, точные метки Intern/Lead и понятные причины конфликтов.
- Добавлен отдельный `grade_conflicts.json`.
- Добавлена безопасная команда `hh-probe` с жёстким ограничением объёма.
- Реальный HH-запрос блокируется, пока не задан настоящий контактный `HH-User-Agent`.
- Добавлена команда `check-run` для проверки целостности готового результата.
- `run_first_version.ps1` собирает и проверяет первую версию одной командой.
- Добавлены документы `FIRST_VERSION.md` и `QUESTIONS_FOR_NIKITA.md`.
- Реальная анонимная HH-проба с контактным заголовком получила `403`; сообщение теперь прямо указывает на необходимость токена приложения.

## 0.5.0

- Разделы «О компании» исключаются из поиска навыков, но сохраняются для аудита.
- Добавлен осторожный поиск повторяющихся рекламных блоков одного работодателя.
- Повторяющиеся требования без рекламных признаков не исключаются.
- Исключённые упоминания навыков сохраняются в `excluded_evidence.json`.
- Добавлены `boilerplate_report.json`, ручной `review_report.json` и читаемый `review_report.html`.
- Формируется `review_decisions_template.json` для решений по вакансиям, кандидатам и рекламным блокам.

## 0.4.0

- Добавлены настраиваемые словари профессиональных действий и объектов.
- Составные формулировки с двумя действиями раскладываются на отдельные понятные кандидаты.
- Поддерживаются русские и английские формы, раздел вакансии, обязательность и отрицание.
- Исходные совпадения сохраняются в `phrase_evidence.json`, сводный список — в `phrase_candidates.json`.
- Кандидаты не меняют канонический словарь и граф без ручного одобрения.

## 0.3.0

- Текст вакансии разбивается на именованные разделы и отдельные фрагменты с позициями и языком.
- Распознаются русские и английские заголовки требований, обязанностей, преимуществ, условий и описания компании.
- Для каждого упоминания навыка сохраняется отдельное доказательство и контекст.
- Отрицание и обязательность определяются в пределах ближайшей части предложения.
- Формула `count` учитывает вес раздела; упоминания в разделе о компании не влияют на граф.
- В нормализованных карточках сохраняются результаты разбора, чтобы их можно было проверить вручную.

## 0.2.0

- Сырые ответы поиска HH сохраняются с запросом, страницей, временем и SHA-256.
- Вакансии хранят все query ID, по которым были найдены.
- Добавлена постоянная история версий вакансий между запусками.
- Архивные и недоступные вакансии сохраняются, но по умолчанию не входят в граф.
- Одинаковые source ID объединяются; вероятные перепубликации попадают в отчёт.
- `unclassified.json` формируется из повторяющихся неизвестных биграмм и триграмм.
- Вес одного работодателя в формуле `count` ограничивается настройкой.
- Добавлена команда `check-config`.

## 0.1.0

- Первый сквозной файловый конвейер.
- Разбор текста, словарное извлечение, временные грейды и `count`.
- Строгие графы Junior, Middle и Senior.
- SVG, словари изображений и курсов, проверки и демонстрационные данные.
