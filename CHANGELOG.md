# Changelog

## Unreleased

- Сбор из веб-интерфейса переведён в фоновые задания: добавлены API состояния, реальный процент выполнения, этапы и счётчики обработанных вакансий/страниц.
- Успешно построенный граф на малом корпусе больше не получает ложный общий статус `failed` только из-за двух верхнеуровневых веток; интерфейс отдельно показывает предупреждения проверки и настоящие ошибки сбора.
- Отсутствие вакансий одного грейда теперь фиксируется полями `grade_vacancy_counts` и `missing_grades`, отображается как предупреждение с рекомендацией расширить выборку и не считается поломкой конвейера.
- Локальная страница переработана вокруг двух реальных источников: HTML-парсера HH и API «Работа России»; удалены действия демо, ручных HH-ссылок, официального HH API и связанные web-маршруты, добавлены параметры и читаемое отображение результата.
- Доведён HTML-сбор HH до пакетного режима: `period_days` передаётся в поиск и проверяется локально, `max_vacancies` стал общим лимитом уникальных вакансий, добавлена консервативная фильтрация профессии по названию.
- Поиск ссылок больше не зависит только от `data-qa`: добавлены fallback по прямым `/vacancy/<id>` и JSON-LD, User-Agent стабилен в пределах сессии, CAPTCHA и HTTP-ограничения по-прежнему не обходятся.
- `collect_all.ps1` включает все 15 профессий и по умолчанию собирает до 3 страниц/50 вакансий за 30 дней; параметры вынесены в аргументы, добавлены паузы и итоговый отчёт об ошибках.
- В пакет проекта добавлены обязательные зависимости `requests` и `beautifulsoup4`; схема, конфигурационная валидация, README и пример HH-конфига синхронизированы с `hh_requests`.
- Переработан сборщик `hh_requests`: убраны жёсткие лимиты на число вакансий со страницы поиска, `items_on_page` теперь берётся из `source.per_page`.
- Извлечение требований полностью переписано: новый `HHDescriptionExtractor` разбирает HTML описания по DOM и `data-qa`, отделяет «Требования» от «Будет плюсом».
- Вакансии теперь получают структурированную зарплату (`salary_from`/`salary_to`/`currency`), `experience_id`, `published_at` в ISO и `query_ids` для корректной дедупликации между запросами.
- Добавлены ретраи с экспоненциальным backoff для страниц вакансий, чтение `retries` из конфига и более строгая капча-детекция.
- Убран хрупкий парсинг по CSS-классам с суффиксами версий вёрстки HH и мертвый код; добавлены тесты `tests/test_hh_requests.py`.
- Сборщик `hh_requests` опирается на JSON-LD `JobPosting`: дата публикации из `datePosted`, зарплата из `baseSalary` (схема `MonetaryAmount`), описание — структурированный HTML из разметки схемы; старые селекторы `data-qa` остаются fallback'ом.
- Описание вакансии сохраняется многострочным (`clean_html`): секции «Требования», «Будет плюсом» больше не сливаются в одну строку и корректно распознаются анализом.
- Ссылки на вакансии фильтруются строго по `hh.ru/vacancy/<id>` — рекламные переходы `adsrv`/`sovetnik` больше не попадают в выборку; `id` и `alternate_url` берутся из итогового URL после редиректов без query-параметров.
- Исправлен `HHDescriptionExtractor`: вложенный `strong` внутри заголовка больше не ломает обход секции, короткие подзаголовки вида «Мы ждем от кандидата:» отбрасываются как шум.
- `_to_vacancy` больше не дублирует «Требования» и «Будет плюсом» в описании; добавлены тесты на JSON-LD, рекламные ссылки и редиректы.
- Извлечение требований: новые шаблоны заголовков «Требования к кандидату», «Ждем от тебя/вас», «Что ожидаем от кандидата», «Мы ожидаем, что вы:»; «Будет плюсом» распознаётся и внутри вложенного `<em><strong>`.
- Маркеры списков «• », «- », «* » убираются из требований и текста описания (`_strip_bullets`).
- Ключевые навыки обогащаются каноническими терминами из `canonical_nodes.json` (см. `source.nodes_path`): найденные в описании навыки добавляются в `key_skills` без дублей; команда `hh-requests` проставляет `nodes_path` автоматически.

## 0.9.0

- Добавлен полностью автоматический сбор вакансий без ключа через официальный открытый API «Работа России».
- По выбранной профессии автоматически используются запросы каталога, период изменений, пагинация и необязательные коды регионов.
- Добавлены команда `public-search`, кнопка в локальном интерфейсе, сохранение сырых ответов и указание источника.
- Поля «Работы России» приводятся к общей модели вакансии: название, работодатель, регион, требования, обязанности, опыт, зарплата и навыки.
- Малые ветки графа автоматически сворачиваются без потери листьев, чтобы реальные выборки проходили строгое правило минимум трёх дочерних нод.
- Реальный проверочный запуск собрал 34 вакансии Python-разработчика и успешно сформировал три графа.

## 0.8.0

- Добавлен ручной импорт прямых публичных страниц вакансий HH без токена.
- Импорт принимает только ссылки `https://hh.ru/vacancy/<id>`, не ищет вакансии автоматически и не обходит CAPTCHA или ограничения.
- Добавлены кнопка в локальном интерфейсе и команда `hh-public`.
- API-сбор разбивает период на настраиваемые временные окна.
- Нормализация файловых вакансий теперь учитывает отдельные поля обязанностей, требований, условий и ключевых навыков.
- Добавлены журнал ручных операций над нодами, сохранение входных запросов, проверка глубины графа, целевого числа листьев и сходства графов грейдов.
- Добавлен подробный отчёт `TZ_COMPLIANCE.md` по 99 требованиям.

## 0.7.0

- Добавлен настраиваемый каталог из 15 IT-профессий и генерация HH-конфигурации по названию или slug.
- Формула `count` приведена к согласованной доле уникальных вакансий в процентах; прежняя взвешенная формула оставлена только как совместимый режим.
- Грейд может определяться по опыту, зарплате, сигналам в тексте или их комбинации; все пороги вынесены в конфигурацию.
- Канонический словарь расширен до 143 стартовых IT-нод.
- Добавлен каталог официальных учебных материалов, нормализация ссылок, проверка провайдера и отчёт покрытия.
- SVG получили пять собственных шаблонов по типу ноды, словарь происхождения и лицензию проекта.
- Добавлены локальная веб-страница и API с отдельными действиями для профессии, демо, HH и проверки результата.
- Добавлена необязательная AI-интеграция для предложений новых нод без автоматической публикации и передачи сырых вакансий.
- Добавлены `run_web.ps1`, новые команды CLI, схемы и автоматические тесты.
