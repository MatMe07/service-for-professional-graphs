# Service for professional graphs

Рабочая версия 0.7 сервиса, который собирает вакансии, выделяет навыки и строит профессиональные графы по Junior, Middle и Senior.

Сейчас весь путь можно проверить без HH на демонстрационных вакансиях. Настоящий сбор HH включится после одобрения приложения и получения токена.

## Что реализовано

- каталог из 15 IT-профессий; количество профессий и поисковые запросы задаются в JSON;
- локальные JSON-файлы вместо базы данных;
- сборщик официального API HH с пагинацией, повторами, сохранением сырых ответов и историей версий;
- очистка HTML, разделы вакансии, обязательность, отрицания и исключение рекламных блоков;
- канонический IT-словарь из 143 нод, синонимы и доказательства каждого совпадения;
- кандидаты новых нод без автоматического изменения утверждённого словаря;
- грейд по опыту, зарплате или их комбинации; пороги вынесены в настройки;
- отдельный отчёт по конфликтам грейда;
- согласованная формула `count`: доля уникальных вакансий грейда, где найден навык, в процентах;
- три строгих JSON-графа: Junior, Middle и Senior;
- SVG пяти типов, словарь изображений и файл лицензии;
- словарь учебных материалов из официальных источников и отчёт покрытия;
- локальная страница с отдельными кнопками для настройки профессии, демо, HH и проверки результата;
- необязательная интеграция DeepSeek, Gemini, OpenAI и совместимого API для предложений новых нод. AI ничего не добавляет автоматически и не получает сырые вакансии;
- автоматические тесты и проверка целостности готовой папки.

Нужен Python 3.12 или новее.


Локальная страница управления:

```powershell

```

Откроется `http://127.0.0.1:8765`. Страница доступна только на этом компьютере.

## 15 стартовых профессий

```powershell
$env:PYTHONPATH = "$PWD\src"
python -m graph_service list-professions
```

В каталог входят Python, Java, Frontend, Fullstack, .NET, C++, Mobile, DevOps, QA, системный и бизнес-анализ, Data Analytics, Data Engineering, Data Science и ML Engineering.

Создать настройку для одной профессии:

```powershell
python -m graph_service init-config `
  --profession python_developer `
  --output data/configs/python_developer.json
```

Названия, псевдонимы, запросы HH, регионы, период и число страниц лежат в `dictionaries/professions.json`.

## Формула count

Для каждого грейда и навыка:

```text
count = число уникальных вакансий с навыком / число всех вакансий профессии этого грейда × 100
```

Повтор навыка внутри одной вакансии не увеличивает `count`. Раздел, обязательность и уверенность сохраняются в `scoring_components.json` для проверки, но не меняют согласованный процент.

## Грейды

В `grade_rules` доступны режимы:

- `experience` — по структурированному опыту HH и годам в тексте;
- `salary` — по зарплате;
- `experience_then_salary` и `salary_then_experience` — основной и запасной признак;
- `combined` — оба признака вместе;
- `signals` — слова Junior, Middle, Senior, Intern и Lead.

Границы лет и зарплат, валюта и политика конфликтов задаются в конфигурации. Intern попадает в Junior, Lead — в Senior, но уточнение сохраняется в отчёте.

## Настоящий HH

После одобрения заявки секреты задаются только через переменные среды:

```powershell
$env:HH_USER_AGENT = "ProfessionalGraphs/0.7 (mlprofessionalgraphs@gmail.com)"
$env:HH_API_TOKEN = "полученный_токен"
$env:PYTHONPATH = "$PWD\src"
python -m graph_service hh-probe --config examples/hh_profession_config.json --limit 5
```

Токен не нужно записывать в JSON, код или Git. Сборщик не обходит CAPTCHA и ограничения HH.

## Необязательные AI-кандидаты

AI выключен по умолчанию. Чтобы его включить, в `ai` указываются `provider` и `model`, а ключ хранится в переменной `PROFESSIONAL_GRAPHS_AI_KEY`. Затем:

```powershell
python -m graph_service ai-suggest `
  --config examples/profession_config.json `
  --run-dir data/runs/<run_id>
```

Команда отправляет только неизвестные фразы и частоту, сохраняет `ai_candidates.json` и никогда сама не правит основной словарь.

## Что пока не окончательное

- HH-сбор ожидает токен по заявке;
- пороги грейдов и политика конфликтов остаются настраиваемыми;
- 143 ноды — стартовое IT-ядро, его ещё нужно утвердить и расширять по реальным данным;
- для базовых технологий используются собственные безопасные SVG-шаблоны; фирменные значки отложены;
- каталог учебных материалов расширяется по мере появления нод в реальных графах;
- вероятные перепубликации и новые профессиональные фразы требуют ручного решения;
- планировщик и база данных не добавлялись: Никита разрешил JSON и запуск по кнопке.

Краткий сценарий показа находится в `FIRST_VERSION.md`, а актуальные вопросы — в `QUESTIONS_FOR_NIKITA.md`.
